# 心动相遇

局域网词语游戏，包含双人心动相遇、2～3 人默契大挑战和 1～4 人语义猜词。

## 安装与启动

需要 Node.js（建议 20 或以上）和 npm。首次运行：

```bash
npm ci
npm run model:download
npm start
```

默认监听 `0.0.0.0:43871`，可用 `PORT` 环境变量更改端口。同一局域网的手机访问 `http://电脑局域网IP:43871/`。`models/` 包含约 130 MB 的模型文件，不纳入 Git；下载脚本从 Hugging Face 的固定版本下载并验证 SHA-256。已有模型时重复运行脚本会检查文件并跳过下载。模型只在进入猜词模式时加载；缺少模型时其他模式仍可使用。

## 猜词模式

选择 1～4 人；1 人点击“开始单人猜词”直接开局，多人可匹配或创建房间。全队共享 100 次不重复的猜测，每次给出语义相似度，页面实时显示前 20 名；输入与目标词相同的词即可获胜，100 次仍未猜中则失败。游戏结束可再来一局。猜词模式是娱乐玩法，不计入战绩或段位。

相似度由本机的 [多语言 MiniLM 模型](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)计算余弦相似度并换算为百分数，负值按 0% 显示，保留小数点后 6 位，非完全一致最高显示 99.999999%；这不是猜中概率，也可能出现不符合直觉的分数。目标词与所有模型运算均留在服务器本机。

微信小程序客户端位于 [miniprogram](miniprogram/README.md)；猜词模式目前只在网页版提供。玩家身份、好友和战绩保存在本地 `friends.json`，包含私人数据，已排除在 Git 之外；需要迁移或备份时请单独妥善保管。敏感词表由 `sensitive-words.json` 维护，简单词库不能保证识别所有变体。
