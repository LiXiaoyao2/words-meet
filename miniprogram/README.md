# 心动相遇 · 微信小程序

这是使用原生微信小程序框架开发的独立客户端，复用上级目录的 Node.js 游戏服务端。支持心动相遇与 2～3 人默契挑战、随机匹配和房间号加入、游戏词语与敏感词校验、头像、弹幕、好友申请/删除/邀请、在线状态、战绩和积分排行。各客户端共用服务端房间、好友和排行榜；小程序与网页各自在设备上保存身份，不自动共用账号。

## 本地开发

1. 在上一级目录运行 `node server.js`。服务默认监听 `0.0.0.0:43871`。
2. 打开微信开发者工具，导入本 `miniprogram` 目录。`project.config.json` 里的 `touristappid` 仅用于本地调试；需要体验版或上线时，改为自己的小程序 AppID。
3. 在 `app.js` 中将 `apiBase` 修改为服务端地址。开发者工具测试局域网 HTTP 时需要开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。客户端和服务端需可互相访问。
4. **真机体验版和正式版不能依赖这个局域网 HTTP 地址。** 需将服务部署到微信认可的 HTTPS 域名，并在小程序后台配置 request 合法域名，替换 `app.js` 中的 `apiBase`；网络证书和域名也需符合微信要求。正式发布还需要有效 AppID 和微信审核。请勿为了连接而关闭线上安全校验。

服务器使用本地 `friends.json` 保存身份、好友及战绩；该文件已加入 `.gitignore`，迁移服务时请私下备份。小程序的身份保存在设备本地，清除小程序数据或换设备后当前版本无法恢复身份。账号、头像等数据会发送到所配置的游戏服务端。

小程序版的成功展示和弹幕使用原生简化效果，不与网页动画完全相同；需要在微信开发者工具和目标手机上验证兼容性。
